MLS-MPM kernel benchmark

Runs the solver's real WGSL kernels on a synthetic slope with the dispatch sequence of MpmSolverNode. Serve the repository root (e.g. npx http-server -c-1 .) and open /mpm-mls-doc/bench/. Query parameters override any setting, e.g. ?particles=65536&gridLayers=12&autorun=1. For unquantised per-stage timings in Chrome enable chrome://flags/#enable-webgpu-developer-features. See mpm-mls-doc/09-performance-analysis.md.
